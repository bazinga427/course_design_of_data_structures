图结构综合实验平台 使用说明

一、平台简介

本平台是“数据结构课程设计”的网页版演示程序，主要用来把图结构的建立、存储、遍历和最大流计算放在同一个页面里展示。页面左侧用于选择功能和控制算法过程，右侧用节点和边把图可视化；计算过程中会用颜色、标签和动画标出当前步骤。

平台不需要注册或登录，启动后直接进入主界面。算法核心使用 C++17，正常情况下通过 WebAssembly（WASM）在浏览器中运行；如果当前环境没有 WASM，程序会自动切换到等价的 JavaScript 实现，不影响课堂演示。

建议使用较新版本的 Edge 或 Chrome 浏览器。

用编辑器打开项目目录，确认终端当前路径是：

然后在终端执行 npm run dev。如果已经安装了项目依赖，会直接给出访问地址；如果没有安装依赖，先执行 npm install。

四、主界面怎么用

1. 顶部工具栏

“打开图文件”用于导入 .txt 图文件。
“载入示例”提供几张内置图，适合快速演示不同算法。
“随机生成”可以指定顶点数、边数、有向或无向、容量范围和随机种子。
“保存图文件”把当前图导出为 .txt，便于下次重新导入。

随机生成时，同一个 seed 会得到同一张图，便于重现实验；Seed 填 0 表示每次生成的结果可以不同。

2. 左侧功能区

左侧有四个功能页签：

物流与供应链
存储结构
遍历 DFS / BFS
最大流最小割

一次只展开一个页签。切换页签后，可以继续操作同一张图。

3. 右侧可视画布

鼠标滚轮可以缩放，拖动节点可以调整位置，“适应窗口”可以重新放满画布。平台提供多种布局，点数很多时力导向布局可能自动换成环形布局，避免页面卡顿。

点击一个节点后，其他面板里的“用选中点”“选中点作 s”“选中点作 t”会使用这个节点。画布还可以显示边权标签、反向边，并导出 PNG 图片。


五、功能介绍

1. 图数据导入、生成与保存

平台支持直接编辑好的文本图文件，也支持从内置示例开始演示。导入后会显示顶点数、边数、有向或无向状态以及文件名。

导出的图文件可以直接放到项目目录，作为下一次的输入文件。当前图数据只存在于当前浏览器页面中，刷新页面或关闭浏览器后需要重新导入，因此重要结果建议及时点“保存图文件”。页面把图画出来后，可以用“导出 PNG”保存图片，方便放进实验报告。

2. 存储结构

“邻接表”按每个顶点列出它的出边，适合观察某个点与哪些点直接相连。
“邻接矩阵”用表格展示边和容量，有连接的位置显示对应数值。
“边表”逐条列出 u、v、容量；计算最大流后，还会显示每条边当前的流量以及是否为割边。

邻接矩阵的直观性强，但空间开销是 O(n²)。顶点数超过 150 时，页面不再铺开矩阵表格，以免内容太长；相关算法仍会正常计算。

3. DFS / BFS 遍历

在这个页签中可以选择 DFS 或 BFS，并指定起点。DFS 使用栈或递归，沿一条路径尽量深入；BFS 使用队列，按距离起点由近到远访问。

点击“计算遍历序列”后，页面会给出访问顺序。可以用“播放”“暂停”“单步”“重置”观察过程，也可以点击序列中的某一步直接跳过去。画布会标出已访问点、当前点和遍历树边。

如果起点无法到达全部顶点，页面会提示本次只覆盖了哪个连通块，其余顶点不属于当前可达范围。

“遍历序列合法性判别”用于检查一串顶点编号是否真的能由 DFS 或 BFS 得到。例如输入：

1 2 3 4 5 6

平台判断的是“这个序列能不能作为某一种合法遍历顺序出现”，而不是要求它与页面默认答案完全一致。同一张图的合法遍历序列可能不止一条，因为同层邻居的访问顺序可以变化。

4. 最大流与最小割

先指定源点 s 和汇点 t。源点表示流量从哪里进入，汇点表示流量最终流向哪里，边上数字表示线路容量。

点击“计算最大流 / 最小割”后，平台使用 Ford-Fulkerson 方法寻找增广路，并显示：

最大流值
最小割容量
增广次数
每一轮增广路径和瓶颈容量
S 侧、T 侧顶点集合
最小割包含哪些边

播放动画时，红色表示当前增广路，绿色表示正在推流的边，蓝色和紫色分别对应源点侧和汇点侧。边上可以切换显示“余额 / 总容量”或“流量 / 总容量”。

计算结束后点击“残量网络”，可以看到最终剩余的容量、已经饱和的边，以及用于撤回流量的反向弧。粉色虚线对应的就是最小割。根据最大流最小割定理，正常情况下最大流值应当等于最小割容量，页面也会显示一致性检查结果。

5. 物流与供应链应用

这个功能把最大流问题放到“工厂—仓库—配送站—门店”的运输场景里：

源点表示供应能力
中间节点表示仓储、分拨能力
汇点表示交付需求
边的容量表示线路运力

点击“载入供应链示例”后，平台会自动计算最大可交付量、瓶颈容量和需求满足率，并列出限制整体运输能力的瓶颈线路。关键线路利用率表示“当前流量 / 线路容量”，比例越接近 100%，说明这条线路越接近满载。

“扩容模拟”可以选择一条瓶颈线路，增加一定容量后重新计算最大可交付量的变化，用于判断新增运力是否值得投入。

“问题定位·线路影响分析”会逐条线路模拟三种情况：

线路中断
运力降级到指定百分比
线路扩容指定容量

分析结果会给出基线可交付量、需求缺口、受影响线路和变化幅度。点击某一条影响结果，右侧画布会高亮对应线路。这个功能解决的不只是“最多能运多少”，还包括“哪条线路出问题影响最大、优先修哪条”。

6. 图结构可视化

画布可以切换布局、调整节点大小、缩放和显示边权。不同算法会用不同颜色标识状态，例如：

青色/深色：已访问或遍历树边
黄色：当前处理节点
红色：本次增广路
绿色：有流量或仍有余量的边
粉色：最小割割边
蓝色/紫色：源点侧和汇点侧

颜色含义也会显示在画布下方，答辩时可以直接按图解释算法执行过程。


六、图文件格式

第一行写：

n m is_directed

n 是顶点数，m 是边数，is_directed 为 1 表示有向图，为 0 表示无向图。之后每行写一条边：

u v capacity

capacity 可以省略，省略时按 1 处理。例如：

6 8 1
1 2 3
1 3 2
2 4 2
3 4 1
4 5 3
5 6 2
2 5 1
3 6 2

平台兼容常见的教材图文件格式：

顶点编号从 0 开始时也能导入，平台会自动映射成从 1 开始的编号并给出提示。
文件开头允许有空行、注释和 UTF-8 BOM。
空格、Tab、逗号、分号都可以作为分隔符。
#、%、// 后面的内容会作为注释忽略。


七、建议的演示顺序

1. 启动平台，载入一张小规模示例图。
2. 在“存储结构”中切换邻接表和邻接矩阵，说明同一张图的两种存储方式。
3. 切到“遍历 DFS / BFS”，选择起点，单步演示遍历过程。
4. 输入一条遍历序列，展示合法性判别。
5. 进入“物流与供应链”，载入示例，查看最大可交付量、瓶颈线路和线路利用率。
6. 做一次扩容模拟和一次线路中断分析，说明最大流最小割在运力规划中的应用。
7. 切到“最大流最小割”，查看增广过程、残量网络和最小割。
8. 最后保存图文件或导出 PNG，作为实验记录。


八、常见问题

1. 终端提示“npm 不是内部或外部命令”

说明 Node.js 或 npm 没有正确安装，或者安装后终端没有重新打开。安装 Node.js LTS 版本后，新开一个 PowerShell 再试。

2. npm run dev 后页面打不开

先确认终端中的项目路径是 D:\课程设计-最终版本\课程设计，再使用终端实际显示的 localhost 地址。不要只关闭终端窗口，否则本地服务会一起结束。

3. 页面没有显示 WASM，但算法还能用

平台默认优先使用 C++/WASM 核心，加载不到时会自动使用 JavaScript 等价实现。右上角状态标签会显示当前使用的核心类型。

4. 最大流结果是 0

先检查图的边方向和源点、汇点是否选对。有向图中从 s 到 t 没有可达路径时，最大流就是 0。

5. 邻接矩阵没有显示完整表格

顶点数超过 150 时，为避免表格过长和浏览器卡顿，页面不再绘制矩阵，但图算法仍然可以正常运行。

6. 刷新后之前的图不见了

当前实现没有把图持久化到浏览器数据库或服务器。刷新前请点击“保存图文件”，需要时重新导入。

7. 端口被占用

关闭占用端口的程序，或让 Vite 自动使用终端提示的下一个端口。也可以手动指定端口：

npm run dev -- --port 5174
